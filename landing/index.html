03 / NEEDLE NOTES

GOOD TO
KNOW.

Does ChampionVibe stream music?

No. Import files you already have. Some features need a one-time model download, but your music files are processed on your device.

Which platforms are supported?

The first release is being prepared for Windows 10 and 64-bit ARM Android devices. Final device testing is still underway.

Do I need Pro to start mixing?

No. The Demo is designed for mixing your own music. Recording and saving a set require Pro.

Where can I get the app?

The first public release is in preparation. Check the GitHub releases page for official installers when they become available.
